# 🔗 TypeLink

> 📱 **用手机作为电脑的语音输入源**。手机说话，文本自动粘贴到电脑光标位置！无需购买麦克风。

---

## ✨ 适用场景

*   🎙️ **台式机无麦克风**：台式机通常没有麦克风，而购买外置麦克风不便且收音效果良莠不齐。使用 TypeLink，直接将手机语音输入法识别的文字粘贴到电脑上。
	**   🚀 **追求高精度语音识别**：嘈杂环境下 ，手机端输入法（如typeless、微信输入法、豆包输入法等）的语音识别和智能断句效果远优于大部分电脑端输入法。使用手机收音识别，体验最顶级的识别精度。
*   ⌨️ **键盘损坏的应急替代**：当电脑键盘突然损坏、按键失效或不便使用时，可以将手机作为备用输入源，在手机上输入文字后自动粘贴至电脑中。
*   🔒 **轻量免安装**：无需在电脑上安装庞大的语音识别模型或繁重的第三方客户端，拷贝即用，极速启动。

---

## 🛠️ 使用方式

1.  **启动桌面端**：双击运行打包好的 `typelink` 应用。
2.  **扫码连接**：桌面端会弹出一个包含二维码的窗口，使用手机摄像头或扫码工具扫描该二维码。
3.  **开始输入**：手机浏览器会自动打开输入网页，点击网页中的输入框。
4.  **语音转文字**：在手机上切换到您最喜欢的语音输入法（如微信输入法、搜狗、讯飞等）开始说话。
5.  **自动粘贴录入**：您在手机上输入并提交的文字，会自动通过桌面端写入电脑系统剪贴板，并模拟执行粘贴指令，出现在电脑当前光标所在的位置。

---

## 🌐 连接方式

项目默认会对电脑上的所有网络接口（如 Wi-Fi、以太网、虚拟网卡、VPN 等）进行**智能评分和排序**，将最有可能连通的真实物理局域网 IP 作为默认展示。如果默认 IP 无法连接，您可以通过扫码界面底部的**“选择网卡 (IP)”下拉菜单**手动切换其他网卡。

支持以下三种常见的连接场景：

*   **同一 WiFi 局域网（无线连接）**：
    确保手机与电脑连接在同一个 Wi-Fi 路由器下。这是最简单、最通用的连接场景。
*   **USB 共享网络（有线连接，极力推荐）**：
    通过 USB 数据线将手机连接到电脑，并在手机上开启 **“USB 网络共享”（Android）** 或 **“个人热点”（iOS，选择 USB 物理连接）**。此时手机和电脑会建立一个专属的有线虚拟网卡通道，连接极快且完全不受外部 Wi-Fi 防火墙或局域网隔离的干扰。
*   **电脑移动热点（无 WiFi 路由时的应急连接）**：
    在电脑上开启 **“移动热点”**，手机连接电脑发射的这个 Wi-Fi 热点。

## 📋 系统要求

*   **运行环境**：
    -   Windows 10/11 或 macOS。
    -   *注：macOS 系统下，首次运行时需要授予应用**辅助功能（Accessibility）**权限，以允许模拟键盘粘贴按键。*
*   **网络条件**：手机与电脑处于同一局域网（WiFi）。
*   **开发依赖**（仅限自行编译）：
    -   Node.js >= 18 (用于运行 Tauri CLI)
    -   Rust toolchain >= 1.77.2

## 📦 打包与编译（免安装绿色版）

本项目已从原先的 Electron 架构全面迁移至 **Tauri v2**，打包出来的绿色版具有**极小体积**与**超低内存占用**。

```bash
cd desktop
npm install
npm run build
```

打包完成后，安装包会生成在以下路径：
*   **macOS**: `desktop/src-tauri/target/release/bundle/macos/` (生成 `.app` / `.dmg`)
*   **Windows**: `desktop/src-tauri/target/release/bundle/nsis/` 或 `msi/` (生成便携版 `.exe` / 安装包)

### ⚡ Tauri 架构优势

*   ✅ **极小体积**：单文件绿色运行，体积仅有约 **3.8MB - 5MB**（相比原 Electron 版的 100MB+，缩减了约 **95%**）。
*   ✅ **超低内存**：运行内存仅约 **30MB**（相比原 Electron 版的 150MB+，降低了约 **80%**）。
*   ✅ **安全纯净**：免安装，即开即用，拷贝即走。
